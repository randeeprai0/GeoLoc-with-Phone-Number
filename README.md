# Phone Geolocation Tracker

This project is a social engineering tool designed to estimate or track the geographic origin of a phone number based on available metadata, telecom prefixes, and public lookup information.

## Purpose

The tool is intended for research, testing, and lawful verification workflows where a phone number's country or region may need to be identified for legitimate operational or security analysis.

## Important Notice

This tool must be used only in compliance with local laws, organizational policies, and privacy requirements. Unauthorized surveillance, stalking, harassment, impersonation, or exploitation of personal data is strictly prohibited.

## Features

- Phone number format validation
- Country and area code detection
- Geolocation inference based on telecom numbering plans
- Basic reporting of likely region or origin
- Educational and testing use for telecom-aware workflows

## Limitations

- Phone numbers do not always reveal exact personal location.
- Some numbers are mobile, VoIP, virtual, or portable across regions.
- Geographic intelligence can be approximate and should not be treated as precise location tracking.
- Public data may be outdated or incomplete.

## Suggested Use Cases
